### Chapter 21: G-METHODS FOR TIME-VARYING TREATMENTS **Technical Focus**: Solutions to bias in traditional methods for time-varying treatments with treatment-confounder feedback, using g-methods (g-formula, IP weighting, g-estimation, doubly-robust estimators).

21.1 The g-formula for time-varying treatments

Context: Extends the g-formula (Chapter 13) to time-varying treatments under sequential exchangeability, positivity, and consistency.
Technical Points:

  • Core Theory: For time-varying treatment A=(A0,A1)A = (A_0, A_1)A=(A0​,A1​), the g-formula for E[Ya0,a1]E[Y^{a_0,a_1}]E[Ya0​,a1​] is:

    ∑l1E[Y∣A0=a0,A1=a1,L1=l1]⋅f(l1∣a0)\sum_{l_1} E[Y \mid A_0=a_0, A_1=a_1, L_1=l_1] \cdot f(l_1 \mid a_0) l1​∑​E[Y∣A0​=a0​,A1​=a1​,L1​=l1​]⋅f(l1​∣a0​)

    where f(l1∣a0)=Pr⁡(L1=l1∣A0=a0)f(l_1 \mid a_0) = \Pr(L_1=l_1 \mid A_0=a_0)f(l1​∣a0​)=Pr(L1​=l1​∣A0​=a0​).
  • Key Formula: Standardizes mean outcome to confounder distribution (L1L_1L1​). Requires positivity: f(l1∣a0)≠0f(l_1 \mid a_0) \neq 0f(l1​∣a0​)=0 for observed (a0,a1,l1)(a_0, a_1, l_1)(a0​,a1​,l1​).
  • Application: In Table 21.1 (sequentially randomized experiment), estimates E[Ya0=1,a1=1]−E[Ya0=0,a1=0]=0E[Y^{a_0=1,a_1=1}] - E[Y^{a_0=0,a_1=0}] = 0E[Ya0​=1,a1​=1]−E[Ya0​=0,a1​=0]=0 (null effect), correcting traditional methods' bias.
  • Generalization: For KKK time points:

    ∑lˉE[Y∣Aˉ=aˉ,Lˉ=lˉ]∏k=0Kf(lk∣aˉk−1,lˉk−1)\sum_{\bar{l}} E[Y \mid \bar{A}=\bar{a}, \bar{L}=\bar{l}] \prod_{k=0}^K f(l_k \mid \bar{a}_{k-1}, \bar{l}_{k-1}) lˉ∑​E[Y∣Aˉ=aˉ,Lˉ=lˉ]k=0∏K​f(lk​∣aˉk−1​,lˉk−1​)

Details Points:

  • Simulation View: Under sequential exchangeability, g-formula simulates counterfactual outcomes under strategy aˉ\bar{a}aˉ.
  • Critical Notes:
    • Omitting confounders (e.g., L1L_1L1​) invalidates causal interpretation.
    • Components (e.g., E[Y∣⋅]E[Y \mid \cdot]E[Y∣⋅]) may lack causal meaning individually.
    • Fine Point 21.1: "History" includes confounders needed for exchangeability, not strictly temporal order.

21.2 IP weighting for time-varying treatments

Technical Points:

  • Weights:
    • Nonstabilized: WAˉ=∏k=0K1f(Ak∣Aˉk−1,Lˉk)W^{\bar{A}} = \prod_{k=0}^K \frac{1}{f(A_k \mid \bar{A}_{k-1}, \bar{L}_k)}WAˉ=∏k=0K​f(Ak​∣Aˉk−1​,Lˉk​)1​
    • Stabilized: SWAˉ=∏k=0Kf(Ak∣Aˉk−1)f(Ak∣Aˉk−1,Lˉk)SW^{\bar{A}} = \prod_{k=0}^K \frac{f(A_k \mid \bar{A}_{k-1})}{f(A_k \mid \bar{A}_{k-1}, \bar{L}_k)}SWAˉ=∏k=0K​f(Ak​∣Aˉk−1​,Lˉk​)f(Ak​∣Aˉk−1​)​
  • Estimation: E[Yaˉ]E[Y^{\bar{a}}]E[Yaˉ] is Eps[Y∣Aˉ=aˉ]E_{\text{ps}}[Y \mid \bar{A}=\bar{a}]Eps​[Y∣Aˉ=aˉ] in pseudo-population created by weights.
  • Marginal Structural Models (MSM): For high-dimensional strategies, specify E[Yaˉ]=β0+β1cum(aˉ)E[Y^{\bar{a}}] = \beta_0 + \beta_1 \text{cum}(\bar{a})E[Yaˉ]=β0​+β1​cum(aˉ). Fit via weighted least squares.

21.3 Doubly robust estimator for time-varying treatments

Technical Points:

  • Approach: Combines g-formula and IP weighting. Consistent if either treatment or outcome model is correct.
  • **Steps for "always treat" (aˉ=1\bar{a}=1aˉ=1):
    1. Fit treatment model πk(Lˉk;α)\pi_k(\bar{L}_k; \alpha)πk​(Lˉk​;α) for Pr⁡(Ak=1∣Aˉk−1=1,Lˉk)\Pr(A_k=1 \mid \bar{A}_{k-1}=1, \bar{L}_k)Pr(Ak​=1∣Aˉk−1​=1,Lˉk​).
    2. Compute time-varying IP weights W^1m\widehat{W}^{1_m}W1m​.
    3. Fit sequential outcome models bm(Lˉm;βm)b_m(\bar{L}_m; \beta_m)bm​(Lˉm​;βm​) with W^1m\widehat{W}^{1_m}W1m​ as covariate.
    4. Estimate E[Yaˉ=1]E[Y^{\bar{a}=1}]E[Yaˉ=1] as sample mean of b0(Lˉ0;β^)b_0(\bar{L}_0; \hat{\beta})b0​(Lˉ0​;β^​).
  • Robustness: K+2K+2K+2-robust (correct if treatment model for times 0:m0:m0:m and outcome model for m+1:Km+1:Km+1:K hold).

Details Points:

  • Extensions: Targeted Minimum Loss-Based Estimator (TMLE) for static/dynamic strategies (Technical Point 21.6).
  • Challenges: Computational complexity; emerging software for machine learning integration.

21.5 Censoring as a time-varying treatment

Technical Points:

  • Handling Censoring: Treat censoring indicators CkC_kCk​ as time-varying treatment.
  • g-formula with Censoring:

    ∑lˉE[Y∣Cˉ=0ˉ,Aˉ=aˉ,Lˉ=lˉ]∏k=0Kf(lk∣ck=0,aˉk−1,lˉk−1)\sum_{\bar{l}} E[Y \mid \bar{C}=\bar{0}, \bar{A}=\bar{a}, \bar{L}=\bar{l}] \prod_{k=0}^K f(l_k \mid c_k=0, \bar{a}_{k-1}, \bar{l}_{k-1}) lˉ∑​E[Y∣Cˉ=0ˉ,Aˉ=aˉ,Lˉ=lˉ]k=0∏K​f(lk​∣ck​=0,aˉk−1​,lˉk−1​)

  • IP Weighting: Use weights WCˉ=∏k=1K+11Pr⁡(Ck=0∣Cˉk−1=0,Aˉk−1,Lˉk−1)W^{\bar{C}} = \prod_{k=1}^{K+1} \frac{1}{\Pr(C_k=0 \mid \bar{C}_{k-1}=0, \bar{A}_{k-1}, \bar{L}_{k-1})}WCˉ=∏k=1K+1​Pr(Ck​=0∣Cˉk−1​=0,Aˉk−1​,Lˉk−1​)1​.

Details Points:

  • Survival Analysis: Extend to failure-time outcomes via hazards models (Technical Point 21.10).
  • Stabilized Weights: Reduce variance by conditioning on past treatment.

21.6 The big g-formula

Technical Points:

  • Concept: g-formula including all variables (measured LLL, unmeasured UUU) under causal DAGs.
  • Identification: If DAG is causal, big g-formula identifies E[Yg]E[Y^g]E[Yg].
  • Front-Door Formula Example: Reduces to ∑mPr⁡(M=m∣A=a)∑a′E[Y∣M=m,A=a′]Pr⁡(A=a′)\sum_m \Pr(M=m \mid A=a) \sum_{a'} E[Y \mid M=m, A=a'] \Pr(A=a')∑m​Pr(M=m∣A=a)∑a′​E[Y∣M=m,A=a′]Pr(A=a′).

Details Points:

  • Non-Observational Formulas: e.g., front-door criterion valid under d-separation (Technical Point 21.11).
  • Limitation: Requires correct causal DAG specification (unverifiable in practice).
